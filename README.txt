MAHEEN NAWAZ RANA — CV WEBSITE

FILES
- index.html: the CV webpage
- photo.jpg: add your authentic classroom photograph here

IMPORTANT PHOTO STEP
1. Choose a real photograph of yourself taken in a classroom or university learning space.
2. Copy it into this same folder.
3. Rename the file exactly: photo.jpg
4. Open index.html in a browser and check that the photograph appears.

PUBLISHING
You can publish this folder using GitHub Pages:
1. Sign in to GitHub and create a new public repository.
2. Upload index.html and photo.jpg to the repository root.
3. Open Settings -> Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for the Pages URL to appear. Open it in a private/incognito browser window to test public access.
7. Submit that exact URL.

CHECK BEFORE SUBMISSION
- Confirm your classroom photo is visible on the live page.
- Confirm the email address is correct.
- Confirm education dates and grades are accurate.
- Open the live URL while signed out to verify public access.

The website is prepared, but the authentic photograph and public hosting must be supplied/completed by you. A local HTML file is not itself a public live link.
